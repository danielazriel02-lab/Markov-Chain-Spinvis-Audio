COMBINED GUITAR - Wicked Game + Lie to Me (Chris Isaak)
========================================================
One guitar layer that blends two songs, like the Kafgenstein mash-up in the tutorial.

  Wicked Game GUITAR (JazzGtr) : 173 tokens   (list 3 in wicked-game-tokens.txt)
  Lie to Me RIFF (clean 1)     : 166 tokens   (list 1 in lie-to-me-tokens.txt)

Both are already in the same key (A minor) and on the same rhythm grid,
so play at the same tempo as your other Wicked Game layers (240, or slower like 180-200).
Single notes only: works in the current sketch.

CROSSING POINTS
The chain can only jump from one song to the other on a token both songs contain.
These 11 tokens appear in both:
  "A3:02", "A3:04", "A3:08", "B3:04", "C4:04", "C4:08", "D4:04", "E4:04", "ZZ:02", "ZZ:04", "ZZ:08"
Use RiTa.markov(2, ...) so one shared token is enough to switch songs.
(With order 3 the chain needs two shared tokens in a row, which only happens 4 times.)
